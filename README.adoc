= AsciiDoc Template

A template repository for converting AsciiDoc documents to HTML and PDF.

== Overview

This repository provides a template for creating documentation using AsciiDoc.
It uses Docker containers to unify the build environment and enables automated builds with GitHub Actions.

== Features

* Convert AsciiDoc to HTML
* Convert AsciiDoc to PDF (with Japanese support)
* Mermaid and D2 diagram support through Kroki
* Dev Container support for a consistent editing environment
* Automated builds with GitHub Actions, including GitHub Pages deployment

== Usage

=== Local Build

Docker Compose or Podman Compose is required. Build using the Compose stack:

[source,bash]
----
# Build the AsciiDoc service image
docker compose -f .devcontainer/app/docker-compose.yml build asciidoctor

# Build HTML and PDF for both languages
docker compose -f .devcontainer/app/docker-compose.yml up \
  --build \
  --abort-on-container-exit \
  --exit-code-from asciidoctor

# Stop and remove the Compose services
docker compose -f .devcontainer/app/docker-compose.yml down
----

Build artifacts are output to `output/en/` and `output/ja/` directories.
The Compose stack starts Kroki and its Mermaid service so diagrams are generated
without requiring a local diagram renderer. Set `KROKI_VERSION` to select a
different Kroki image version.

=== Dev Container

Open the repository in VS Code and reopen it in the Dev Container to use the
provided editor extensions and Kroki integration. The `app` service is the
development workspace; the `asciidoctor`, `kroki`, and `kroki-mermaid` services
are used for document builds.

=== Build with GitHub Actions

You can run the build in one of the following ways:

. **On tag push**: Pushing a tag in `v*.*.*` format automatically triggers the build
. **Manual execution**: You can manually run it from the "Run workflow" button in GitHub Actions

The English HTML output is also deployed to GitHub Pages. All generated HTML
and PDF files can be downloaded from the `asciidoc-output` artifact, which is
retained for 30 days.

When changes are pushed to `main`, the Docker image workflow publishes the
AsciiDoc builder image to GitHub Container Registry at
`ghcr.io/<owner>/<repository>/adoc-builder:latest`.

== Customization

=== Editing Documents

Edit `docs/en/index.adoc` (English) or `docs/ja/index.adoc` (Japanese) to change the document content.
Common settings are managed in `config.adoc` in each language directory.

=== Changing PDF Style

Edit `docs/pdf-configs/style.yml` for the English PDF or
`docs/pdf-configs/styles-ja.yml` for the Japanese PDF to customize the PDF
appearance. `styles-en.yml` contains the English-specific theme settings.

=== Adding Diagrams

Add Mermaid or D2 source to the language document and reference it using the
AsciiDoc Kroki integration. D2 diagrams use SVG output for PDF generation,
while Mermaid diagrams use PNG output for consistent font rendering.

= AsciiDoc Template (日本語)

AsciiDocドキュメントをHTMLおよびPDFに変換するためのテンプレートリポジトリです。

== 概要

このリポジトリは、AsciiDocを使用したドキュメント作成のためのテンプレートを提供します。
Dockerコンテナを使用してビルド環境を統一し、GitHub Actionsで自動ビルドを実行できます。

== 機能

* AsciiDocからHTMLへの変換
* AsciiDocからPDFへの変換（日本語対応）
* Krokiを利用したMermaidおよびD2図のサポート
* 一貫した編集環境を利用できるDev Container対応
* GitHub Pagesへのデプロイを含むGitHub Actionsによる自動ビルド

== 使い方

=== ローカルでのビルド

Dockerを使用してビルドします:

[source,bash]
----
# AsciiDocビルド用サービスをビルド
podman compose -f .devcontainer/app/docker-compose.yml build asciidoctor

# ドキュメントのビルド実行（HTML/PDF生成）
podman compose -f .devcontainer/app/docker-compose.yml up \
  --build \
  --abort-on-container-exit \
  --exit-code-from asciidoctor

# 後片付け
podman compose -f .devcontainer/app/docker-compose.yml down
----

ビルド成果物は `output/en/` と `output/ja/` ディレクトリに出力されます。
ComposeスタックはKrokiおよびMermaidサービスも起動するため、ローカルに
図のレンダラーをインストールせずに図を生成できます。使用するKrokiの
イメージバージョンは `KROKI_VERSION` で変更できます。

=== Dev Container

リポジトリをVS Codeで開き、Dev Containerで再度開くと、提供されている
拡張機能とKroki連携を利用できます。`app`サービスが開発用ワークスペース、
`asciidoctor`、`kroki`、`kroki-mermaid`サービスがドキュメントビルド用です。

=== GitHub Actionsでのビルド

以下のいずれかの方法でビルドを実行できます:

. **mainへのプッシュ時**: `main`ブランチへのプッシュでビルドが実行されます
. **タグプッシュ時**: `v*.*.*` 形式のタグをプッシュすると自動的にビルドが実行されます
. **手動実行**: GitHub Actionsの「Run workflow」ボタンから手動で実行できます

英語HTMLはGitHub Pagesにもデプロイされます。生成されたHTMLおよびPDFは
`asciidoc-output` Artifactからダウンロードでき、保存期間は30日です。

`main`への変更時には、DockerイメージのワークフローがAsciiDocビルダー
イメージをGitHub Container Registryの
`ghcr.io/<owner>/<repository>/adoc-builder:latest`へ公開します。

== カスタマイズ

=== ドキュメントの編集

`docs/en/index.adoc`（英語）または `docs/ja/index.adoc`（日本語）を編集してドキュメントの内容を変更します。
共通設定は各言語ディレクトリの `config.adoc` で管理されています。

=== PDFスタイルの変更

英語PDFは `docs/pdf-configs/style.yml`、日本語PDFは
`docs/pdf-configs/styles-ja.yml` を編集して見た目をカスタマイズできます。
`styles-en.yml` には英語固有のテーマ設定が含まれています。

=== 図の追加

言語別ドキュメントにMermaidまたはD2のソースを追加し、AsciiDocのKroki
連携を使って参照します。PDF生成では、D2図はSVG、Mermaid図はフォントを
安定して描画するためPNGとして出力されます。
